# Rocky Toolkit

A collection of small Bash scripts for everyday tasks on Rocky Linux.
I am building this project to learn Linux and Git.

## What is inside

- `scripts/` - the Bash scripts live here

## How to use

```bash
git clone git@github.com:insync22/rocky-toolkit.git
cd rocky-toolkit
chmod +x scripts/*.sh
./scripts/yourscript.sh
```

## Goals

- Learn Linux: files, permissions, users, scheduled tasks
- Learn Git: commits, branches, merging
